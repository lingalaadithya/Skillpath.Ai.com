# ✦ SkillPath AI

### Learn • Practice • Build • Grow

SkillPath AI is a modern learning platform designed to help students and developers discover useful technology skills, practice typing, follow structured learning roadmaps, interact with a learning mentor, and build practical projects.

The platform combines learning resources, interactive practice, project ideas, and guided learning paths in one clean interface.

## ⌨️ Typing Skill

SkillPath AI includes an interactive typing practice system with **10 progressive levels**.

### Difficulty Structure

| Levels | Difficulty   |
| ------ | ------------ |
| 1 – 3  | 🟢 Easy      |
| 4 – 5  | 🟡 Medium    |
| 6 – 8  | 🟠 Hard      |
| 9 – 10 | 🔴 Very Hard |

The typing system tracks:

* ⚡ Words Per Minute
* 🎯 Accuracy
* ❌ Errors
* ⏱️ Time
* 🔤 Characters
* 📈 Level progress

The timer begins when typing starts.

After completing Level 10, users can continue with **advanced paragraph typing practice** to improve speed and accuracy.

Typing progress and best results can be stored locally in the browser.

# ⚙️ Installation

## 1. Clone the repository

```bash
git clone https://github.com/lingalaadithya/skilldev.ai.git
```

Move into the project:

```bash
cd skilldev.ai
```

---

## 2. Install dependencies

Run:

```bash
npm install
```

---

## 3. Start the application

Run:

```bash
npm start
```

The application will start on:

```text
http://127.0.0.1:3000/
```

---

# 🧪 Test the Server

You can check whether the backend is running by opening:

```text
http://127.0.0.1:3000/test
```

A successful response confirms that the SkillPath AI server is running.
